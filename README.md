# متانما (Metanama)

سایتی کاملاً استاتیک برای دیدن، ویرایش و حذف کامل متادیتای پنهان در فایل‌های عکس و موزیک.
تمام پردازش با جاوااسکریپت داخل مرورگر کاربر انجام می‌شود؛ هیچ فایلی به هیچ سروری ارسال نمی‌شود و این پروژه هیچ بک‌اندی ندارد.

## ساختار پروژه

```
metanama/
├── index.html          صفحه‌ی اصلی
├── photo.html           ابزار متادیتای عکس (EXIF)
├── music.html            ابزار تگ موزیک (ID3)
├── site.webmanifest
└── assets/
    ├── css/style.css
    ├── js/
    │   ├── main.js       رفتار مشترک سایت (منو، تب‌ها، توست)
    │   ├── photo.js       منطق ابزار عکس (exifr برای خواندن، piexifjs برای ویرایش/حذف JPEG)
    │   ├── id3.js         موتور خواندن/نوشتن تگ ID3v2 (بدون وابستگی خارجی)
    │   └── music.js       منطق ابزار موزیک
    └── img/               لوگو، آیکن‌ها، عکس توسعه‌دهنده
```

## راه‌اندازی روی GitHub Pages

۱. یک ریپازیتوری جدید در گیت‌هاب بسازید (مثلاً به نام `metanama`).

۲. تمام فایل‌های همین پوشه را در ریشه‌ی ریپازیتوری قرار دهید و پوش کنید:

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/<username>/<repo>.git
git push -u origin main
```

۳. در گیت‌هاب به مسیر Settings → Pages بروید و در بخش Source گزینه‌ی «Deploy from a branch» را انتخاب کنید؛ شاخه‌ی `main` و پوشه‌ی `/ (root)` را انتخاب و ذخیره کنید.

۴. برای استفاده از دامنه‌ی اختصاصی `metanama.ir`:
   - یک فایل به نام `CNAME` (بدون پسوند) در ریشه‌ی پروژه بسازید که فقط شامل این خط باشد:
     ```
     metanama.ir
     ```
   - در پنل مدیریت دامنه، یک رکورد `A` برای دامنه‌ی اصلی به آی‌پی‌های گیت‌هاب پیج بسازید:
     ```
     185.199.108.153
     185.199.109.153
     185.199.110.153
     185.199.111.153
     ```
   - در همان بخش Settings → Pages، نام دامنه‌ی `metanama.ir` را وارد کنید و گزینه‌ی «Enforce HTTPS» را بعد از فعال‌شدن گواهی، تیک بزنید.

## نکات فنی

- **ابزار عکس**: خواندن متادیتا با کتابخانه‌ی [exifr](https://github.com/MikeKovarik/exifr) و ویرایش/حذف فیلدهای EXIF در فایل‌های JPEG با [piexifjs](https://github.com/hMatoba/piexifjs) انجام می‌شود. «حذف کامل متادیتا» با بازترسیم تصویر روی `<canvas>` برای هر فرمتی (JPEG/PNG/WEBP) کار می‌کند، چون خروجی canvas ذاتاً هیچ متادیتایی حمل نمی‌کند.
- **ابزار موزیک**: خواندن و نوشتن تگ ID3v2.3 با یک موتور کوچک و مستقل (`id3.js`) نوشته شده، بدون هیچ وابستگی خارجی. متن‌ها با UTF-16 نوشته می‌شوند تا نام‌های فارسی هم درست ذخیره شوند. در حال حاضر فقط فایل‌های **MP3** پشتیبانی می‌شوند.
- هر دو کتابخانه‌ی خارجی (`exifr`, `piexifjs`) از CDN بارگذاری می‌شوند، بنابراین برای اجرای سایت نیازی به build یا npm نیست — همین فایل‌ها را مستقیم روی هر هاست استاتیکی (از جمله GitHub Pages) آپلود کنید.

## سئو (SEO)

- **عنوان و توضیحات هر صفحه** جدا و کلیدواژه‌محور نوشته شده (خانه / ابزار عکس / ابزار موزیک)، همراه با `canonical`، Open Graph و Twitter Card کامل.
- **Structured Data (JSON-LD)**: `WebSite` و `Organization` در خانه، `SoftwareApplication` و `BreadcrumbList` در هر ابزار، و `FAQPage` در هر سه صفحه (منطبق با متن قابل‌مشاهده).
- **محتوای توضیحی (SEO content)** درباره‌ی اگزیف و ID3 به هر صفحه‌ی ابزار اضافه شده تا علاوه بر فرم، محتوای متنی واقعی هم برای ایندکس‌شدن وجود داشته باشد.
- **بخش سوالات متداول** با آکاردئون در هر سه صفحه، هم‌راستا با schema مربوطه.
- `robots.txt` و `sitemap.xml` در ریشه‌ی پروژه.
- صفحه‌ی ۴۰۴ اختصاصی (`404.html`) که گیت‌هاب‌پیج به‌صورت خودکار برای مسیرهای نامعتبر نمایش می‌دهد.
- Breadcrumb قابل‌مشاهده در بالای هر صفحه‌ی ابزار.
